# KRINO 娘 · DSH 桌宠

住在 DeepSeek Harness 里的 Q 版 KRINO 娘。

- **会动**：13 段动漫动作（待机、推眼镜、东张西望、伸懒腰、打瞌睡、挥手、开心蹦跳、被戳吓一跳、点头、思考、看书、敲键盘、比 V），都从同一个姿势开始、回到同一个姿势结束，怎么接都流畅不跳。
- **陪你干活**：AI 在工作时她看书、敲键盘、托腮思考；需要你确认时挥手提醒；做完了比个 V；很久没动静她会打瞌睡。
- **能互动**：点她会害羞、蹦跳；按住拖到哪里就待在哪里（会记住位置）。
- **捏一个自己的伙伴**：鼠标移到她身上，点头顶的「捏一个自己的伙伴 ↗」，去 [KRINO 世界](https://www.krinomatrix.com) 的工作台用一句话设定灵魂和样子——人、动物、机器人都行。

## 安装

在 DSH 的「插件管理」里搜 `dsh-pet-krino` 安装；或者命令行：

```bash
dsh plugin --profile web add dsh-pet-krino
```

装好后重启 `dsh web`。

## 设置

插件设置页可以改：桌宠高度（默认 180 像素）、是否显示气泡、「捏一个自己的伙伴」打开的网址。

## 说明

- 支持 Chrome / Edge / DSH 桌面端。Safari 不支持透明视频，会显示静态立绘。
- 插件只读：不读你的对话内容，只看 AI 是「在干活 / 等你确认 / 做完了」这几种状态。
- 适配 DSH 0.2.0-rc.2。
