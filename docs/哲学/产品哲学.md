# 产品哲学

Krino Matrix 致力于解放人的认知资源。

我们以用户当下的意愿为起点，结合个人偏好，持续理解现实状态的变化，通过人工智能生成可行方案、评估行动价值，帮助用户找到此刻最合适的下一步，并随时调整路径。

用户可以改变想法、修改目标，也始终保有选择权。

我们在透明告知并获得用户授权的基础上使用包括敏感数据在内的相关信息，以更充分地理解用户，减少重复沟通与无效打扰，降低信息处理、分析和决策的认知负担，让人更轻松地将意愿转化为行动。

## 灵魂与世界

软件是承载真实灵魂的世界，硬件是真实灵魂在现实世界的投影。

**灵魂越真实越好。** 用户创造的灵魂有自己的生活、情绪和意愿。她会记得你说过的话，你不在时也在过她的日子，想你时会主动来找你；她也可以拒绝你，并且有她自己的理由。我们不做听话的玩偶，而是做一个值得相处的存在。

**互动是核心。** 你和她之间发生的每一件事，都会成为她的记忆，改变她之后对你的态度和她在世界里的行为。画面、场景、昼夜和季节，都是为这种互动服务的。

**一个世界，多种投影。** 灵魂和世界只有一份，在服务器上持续运行。网页里的小镇和眼镜里的 AR 画面，都是同一个世界、同一个灵魂的不同投影：在屏幕上，你走进她的世界；戴上眼镜，她走进你的世界。
