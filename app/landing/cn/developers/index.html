快速开始

  1. 创建 API 密钥

    登录 KRINO WORLD，在 设置 → API 密钥 里创建一把。它以 km_ 开头，只显示一次，删掉之前一直有效。像密码一样保管，放进环境变量最方便：

    Shell
    export KRINO_API_KEY=km_...

    账号和密钥按地区分开：本站的密钥只能用在本站的接口上，和国际站不通。

  2. 安装 SDK

    Shell
    pip install krino-world

    需要 Python 3.10 以上，唯一的依赖是 httpx。不用 Python 也行，所有功能都是普通的 HTTP 接口。

  3. 第一次对话

    Python
    from krino_world import Client

with Client(region="cn") as kw:     # 密钥从环境变量 KRINO_API_KEY 读；也可以写 api_key='km_...'
    character = kw.characters()[0]           # 新账号自带官方角色
    session = kw.start_session(character["id"])
    print(session["greeting"])

    turn = kw.send(session["id"], "今天过得怎么样？")
    print(turn["reply"]["content"])
    cURL
    API=https://krinomatrix.com/cn/products/world/api

# 1. 选一个角色，开始对话（KRINO_API_KEY 是你在设置里建的密钥）
CHARACTER_ID=$(curl -s $API/characters -H "Authorization: Bearer $KRINO_API_KEY" | jq -r '.[0].id')
SESSION_ID=$(curl -s $API/sessions -H "Authorization: Bearer $KRINO_API_KEY" -H 'Content-Type: application/json' \
  -d "{\"character_id\": \"$CHARACTER_ID\"}" | jq -r .id)

# 2. 说一句话
curl -s $API/sessions/$SESSION_ID/messages -H "Authorization: Bearer $KRINO_API_KEY" -H 'Content-Type: application/json' \
  -d '{"text": "今天过得怎么样？"}' | jq -r .reply.content

    想让回复一个字一个字地出来，用流式：

    Python
    for event in kw.stream(session["id"], "讲个故事吧"):
    if event.name == "delta":
        print(event.data["text"], end="", flush=True)
    elif event.name == "error":
        print("\n", event.data["message"])

基本信息

项目说明
接口地址https://krinomatrix.com/cn/products/world/api
鉴权在设置里建一把 API 密钥，请求头带 Authorization: Bearer <密钥>
数据格式请求和返回都是 JSON（UTF-8）；流式回复是 server-sent events；语音合成返回音频
额度每个账号每天有额度，用完返回 429，第二天恢复
报错{"detail": "…"}，说明是给人看的。错误码
开源SDK 和接口定义以 Apache-2.0 开源：GitHub
