// API

API 参考

KRINO WORLD 的 HTTP 接口。这里列出常用的接口；全部接口（包括角色编辑、工坊、社交圈、眼镜）的完整定义在 openapi.json（OpenAPI 3.1）。

接口地址

Base URL
https://krinomatrix.com/cn/products/world/api

下面的路径都接在这个地址后面，比如 POST /auth/login 就是 https://krinomatrix.com/cn/products/world/api/auth/login。另一个地区是独立的部署，账号和数据各自分开。自己部署的服务器在 http://<主机>:8630/api。

鉴权

登录应用，在 设置 → API 密钥 里创建一把密钥（以 km_ 开头，只显示一次），之后每个请求带上 Authorization: Bearer <密钥>。密钥删掉之前一直有效；泄露了就在设置里删掉，用它的程序马上失效。

密钥能做应用里能做的一切，只有管理密钥和注销账号不行（返回 403），这两件要在网页上登录后操作。也可以用 密码登录 拿一个登录 token 代替密钥，它一周后过期。

Shell
API=https://krinomatrix.com/cn/products/world/api
export KRINO_API_KEY=km_...   # 设置 → API 密钥 里创建

curl -s $API/characters -H "Authorization: Bearer $KRINO_API_KEY"

流式回复

POST /sessions/{sid}/stream 用 server-sent events 返回，顺序是：

事件内容
decision最先到：这一轮角色决定做什么（回复、保持安静、做个动作……）
delta回复的一小段文字 text，按顺序拼起来就是整句
done结束，内容和 /messages 的返回一样
error生成中途失败时代替 done：{"message": "…"}
text/event-stream
event: decision
data: {"actions": ["RESPOND"], "policy": "rules"}

event: delta
data: {"text": "从前，"}

event: delta
data: {"text": "有一头大蓝鲸……"}

event: done
data: {"reply": {…}, "user": {…}, "actions": […], "decision": {…}, "memory_job": "…"}

自己在前面加反向代理的话，要给这个接口关掉响应缓冲。

错误码

出错时返回 {"detail": "…"}，说明是给人看的，用本站的语言。

状态码意思
400请求不完整，比如消息是空的
401没带密钥、密钥已删除，或登录 token 过期了
403API 密钥不能做这件事（管理密钥、注销账号要在网页上登录后操作）
404不存在，或者不是你的
409对话属于另一个角色
413 / 415上传的文件太大 / 格式不支持
422请求体和参数格式对不上，detail 里说明是哪个字段
429今天的额度用完了，第二天恢复
502 / 503上游的模型或语音服务出错，重试一般就好

账号

注册

POST/auth/register无需登录

新建账号并直接登录。新账号自带官方角色，可以马上开始对话。

参数

参数位置类型必填说明
username请求体string必填用户名
password请求体string必填密码6–128字
display_name请求体string可选显示的名字，不填就用用户名

请求示例

cURL
curl "$API/auth/register" \
  -H 'Content-Type: application/json' \
  -d '{"username": "me", "password": "your-password"}'

返回示例

JSON
{
  "token": "2wIk7-Ecvo7oSW2Qo1IsO_Nh2S-aDo_Nxe0-bFh0HvQ",
  "user": {
    "id": "58acfe8dca7b4a02ab9cbea54767adb8",
    "username": "me",
    "display_name": "me",
    "settings": {…}
  }
}

修改设置

PATCH/me需要登录

只传要改的字段。设置分组的结构和 GET /me 返回的 settings 一样，组内也只需传要改的项。

参数

参数位置类型必填说明
display_name请求体string可选显示的名字，不填就用用户名
save_sensitive请求体bool可选允许角色记住敏感信息（健康、财务等）
privacy请求体object可选隐私：camera、microphone
voice请求体object可选语音：stt、tts、autoplay、voice
interaction请求体object可选互动：proactive（角色主动搭话）、idle_seconds、stories、web 等
evaluator请求体object可选互动策略：mode
social请求体object可选社交圈：autonomy、share_life

请求示例

cURL
curl -X PATCH "$API/me" \
  -H "Authorization: Bearer $KRINO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"display_name": "Mika", "voice": {"autoplay": false}}'

{

  "username": "me",

  "settings": {
    "save_sensitive": false,

发消息

POST/sessions/{sid}/messages需要登录

说一句话，等角色的完整回复。要边生成边显示用下面的流式接口。

参数

参数位置类型必填说明
sid路径string必填对话 id
text请求体string可选你说的话≤ 4000字
audio请求体string可选一段录音，data URL（data:audio/wav;base64,…），角色直接听；只有流式接口用
image请求体string可选一张图片，data URL（data:image/jpeg;base64,…）
source请求体string可选从哪发来的：app、voice（语音对话）、glasses（眼镜）app / voice / glasses；默认 "app"
character_id请求体string可选可选：校验对话属于这个角色，不是就返回 409

请求示例

cURL
curl "$API/sessions/$SESSION_ID/messages" \
  -H "Authorization: Bearer $KRINO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"text": "今天过得怎么样？"}'

返回示例

JSON
{
  "reply": {
    "id": 90,
    "role": "assistant",
    "content": "嗯，我在。今天顺利吗？",
    "state": {"expression": "happy", "animation": null, "mood": "happy"},
    "created_at": "2026-11-13T14:34:05+00:00"
  },
  "user": {"id": 89, "role": "user", "content": "今天过得怎么样？", …},
  "actions": [{"type": "say", "text": "嗯，我在。今天顺利吗？"}],
  "decision": {"policy": "rules", "primary": {"action": "RESPOND", …}, …},
  "memory_job": "40a37bb9a38c48a580d9a67e454f49cb"
}

互动事件

POST/sessions/{sid}/events需要登录

参数

参数位置类型必填说明
sid路径string必填对话 id
type请求体string必填gesture（手势）、idle（你走开了）、perception（给角色看画面）idle / gesture / perception
gesture请求体string可选手势名，比如 wave、pat
idle_count请求体int可选连续第几次空闲0–100；默认 1
text请求体string可选附带的一句话（可选）≤ 400字
image请求体string可选一张图片，data URL（data:image/jpeg;base64,…）
character_id请求体string可选可选：校验对话属于这个角色，不是就返回 409

请求示例

cURL
curl "$API/sessions/$SESSION_ID/events" \
  -H "Authorization: Bearer $KRINO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"type": "gesture", "gesture": "wave"}'

返回示例

{

添加记忆

POST/memories需要登录

自己告诉角色一件事，让它记住。

参数

参数位置类型必填说明
character_id请求体string必填角色 id
content请求体string必填记忆内容1–2000字
type请求体string可选fact 事实、preference 偏好、event 事件、commitment 约定fact / preference / event / commitment；默认 "fact"
reality请求体string可选real 真实发生的、story 一起编的故事real / story；默认 "real"
title请求体string可选短标题，不填就从内容截取
importance请求体int可选重要程度 1–51–5；默认 3
pinned请求体bool可选置顶：每次对话都想得起来默认 false
sensitive请求体bool可选敏感信息默认 false
source_message_id请求体int可选出自哪条消息（消息的 id）

请求示例

cURL
curl "$API/memories" \
  -H "Authorization: Bearer $KRINO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d "{\"character_id\": \"$CHARACTER_ID\", \"content\": \"我喜欢吃白米饭\", \"type\": \"preference\"}"

返回示例

语音与视觉

语音合成

POST/voice/tts需要登录

把文字读出来，返回音频本身（不是 JSON）。看 Content-Type 判断格式。

参数

参数位置类型必填说明
text请求体string必填要读的文字1–600字
voice请求体string可选声音 id，可选值见 GET /voice/config；不填用默认
rate请求体number可选语速 0.5–2.00.5–2；默认 1.0
style请求体string可选声音描述（一句话生成的角色才有）
stream请求体bool可选边合成边返回 16-bit PCM（24 kHz 单声道），第一段声音零点几秒就到默认 false
opus_stream请求体bool可选流式时也压成 Ogg Opus（浏览器用 WebCodecs 边收边解）默认 false
opus_file请求体bool可选整句返回 Ogg Opus 而不是 WAV，小很多默认 false

请求示例

cURL
curl "$API/voice/tts" \
  -H "Authorization: Bearer $KRINO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"text": "晚安", "opus_file": true}' \
  -o speech.ogg

返回示例

Shell
# 返回的是音频字节
Content-Type: audio/ogg   # opus_file=false 时是 audio/wav
