// PYTHON SDK

Python SDK

krino-world 把接口包成了几十个方法，返回普通的 dict 和 list。 v0.2.0 · PyPI · 源码

安装

Shell
pip install krino-world

需要 Python 3.10 以上，唯一的依赖是 httpx。

Python
from krino_world import Client

with Client(region="cn") as kw:     # 密钥从环境变量 KRINO_API_KEY 读；也可以写 api_key='km_...'
    character = kw.characters()[0]           # 新账号自带官方角色
    session = kw.start_session(character["id"])
    print(session["greeting"])

    turn = kw.send(session["id"], "今天过得怎么样？")
    print(turn["reply"]["content"])

Client

Client(region="global", base_url=None, api_key=None, token=None, timeout=120)
参数说明
region"cn" 中国大陆站，"global" 国际站。两边账号不通
base_url连自己部署的服务器，比如 http://127.0.0.1:8630（填了就不看 region）
api_key设置 → API 密钥 里建的密钥（km_ 开头）。不填就读环境变量 KRINO_API_KEY
token已有的登录 token（用密码登录时拿到的），不用再登录
timeout请求超时，秒

用 with 会在结束时关掉连接；不用 with 就自己调 close()。没有 API 密钥时也可以 kw.login(用户名, 密码)，拿到的 token 一周后过期。

通用请求

request(method: str, path: str, **kwargs) -> Any

调用 /api/ 下的任意接口（上面没有专门方法的），返回解析好的 JSON。其余参数原样交给 httpx。

账号

register(username: str, password: str, display_name: str | None=None) -> dict

注册并登录，token 存在客户端上。返回账号信息。

login(username: str, password: str) -> dict

用密码登录（没有 API 密钥时用），token 存在客户端上，一周后过期。返回账号信息。

logout() -> None

退出登录，token 失效。

me() -> dict

账号和设置。

health() -> dict

服务是否在线。

角色

characters() -> list[dict]

你的角色，新的在前。新账号自带官方角色。

character(character_id: str) -> dict

一个角色的完整资料。

export_character(character_id: str) -> dict

导出成 krino-persona/1 角色包。

对话

sessions(character_id: str) -> list[dict]

和某个角色的所有对话。

start_session(character_id: str) -> dict

开始新对话，返回里有开场白 greeting。

session(session_id: str) -> dict

一段对话和全部消息。

send(session_id: str, text: str, image: str | None=None, source: str='app') -> dict

说一句话，等完整回复。回复文字在 turn["reply"]["content"]。

stream(session_id: str, text: str='', image: str | None=None, audio: str | None=None, source: str='app') -> Iterator[Event]

说一句话，回复一段段到：逐个产出 Event。

gesture(session_id: str, gesture: str) -> dict

做个手势（wave、pat……），角色自己决定怎么回应。

end_session(session_id: str) -> dict

结束对话，角色写一份小结。

delete_session(session_id: str) -> None

删除对话。

记忆

memories(character_id: str, status: str='active', type: str | None=None, q: str | None=None) -> list[dict]

角色记得的关于你的事，可按状态、类型、关键词筛选。

remember(character_id: str, content: str, type: str='fact', reality: str='real', importance: int=3, **fields) -> dict

告诉角色一件事让它记住。type：fact / preference / event / commitment。

edit_memory(memory_id: str, **fields) -> dict

改一条记忆，只传要改的字段。

forget(memory_id: str) -> dict

忘掉一条记忆，restore() 能找回。

restore(memory_id: str) -> dict

找回忘掉的记忆。

delete_memory(memory_id: str) -> None

彻底删除一条记忆。

语音

speak(text: str, voice: str | None=None, rate: float=1.0) -> tuple[bytes, str]

语音合成，返回 (音频字节, 媒体类型)。

Event

stream() 产出的事件，有 name 和 data 两个字段。name 是 decision、delta、done 或 error，含义见 流式回复。

Python
for event in kw.stream(session["id"], "讲个故事吧"):
    if event.name == "delta":
        print(event.data["text"], end="", flush=True)
    elif event.name == "error":
        print("\n", event.data["message"])

KrinoError

服务器拒绝请求时抛出：.status 是 HTTP 状态码，.message 是服务器给的说明。

Python
from krino_world import Client, KrinoError

try:
    kw.send(session["id"], "")
except KrinoError as e:
    print(e.status, e.message)   # 400 消息不能为空
