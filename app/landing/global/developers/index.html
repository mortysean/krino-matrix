Quick start

  1. Get an account

    Sign up in KRINO WORLD, or call the register endpoint. Accounts belong to one region: an account here works only with this site’s API, not with the mainland China site.

  2. Install the SDK

    Shell
    pip install krino-world

    Python 3.10 or newer; its only dependency is httpx. No Python? Everything is a plain HTTP endpoint.

  3. Say hello

    Python
    from krino_world import Client

with Client(region="global") as kw:
    kw.login("me", "your-password")         # or kw.register(...); the token is kept on the client
    character = kw.characters()[0]           # a new account already has the official characters
    session = kw.start_session(character["id"])
    print(session["greeting"])

    turn = kw.send(session["id"], "How was your day?")
    print(turn["reply"]["content"])
    cURL
    API=https://krinomatrix.com/global/products/world/api

# 1. Log in and keep the token
TOKEN=$(curl -s $API/auth/login -H 'Content-Type: application/json' \
  -d '{"username": "me", "password": "your-password"}' | jq -r .token)

# 2. Pick a character and start a session
CHARACTER_ID=$(curl -s $API/characters -H "Authorization: Bearer $TOKEN" | jq -r '.[0].id')
SESSION_ID=$(curl -s $API/sessions -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d "{\"character_id\": \"$CHARACTER_ID\"}" | jq -r .id)

# 3. Say something
curl -s $API/sessions/$SESSION_ID/messages -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"text": "How was your day?"}' | jq -r .reply.content

    To show the reply as it's written, stream it:

    Python
    for event in kw.stream(session["id"], "Tell me a story"):
    if event.name == "delta":
        print(event.data["text"], end="", flush=True)
    elif event.name == "error":
        print("\n", event.data["message"])
