For developers

We're turning what powers our characters into public APIs, with API docs, SDK docs and SDKs. The API, SDKs, client and inference framework will be open source; persona, memory and relationships stay closed. The docs aren't public yet; if you'd like early access or to help test, drop us a line.

OPEN SOURCE

Open source

API definitions, SDKs, a reference client and the inference framework, open for you to read, change and deploy.

These are directions we're working on, not features that are available today (progress on the Krino Tree). Contact: support@krinomatrix.com (subject "Developer access").
