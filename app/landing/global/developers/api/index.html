// API

API reference

The KRINO WORLD HTTP API. The common endpoints are here; the full definition of every endpoint (including the character editor, workshop, social circle and glasses) is in openapi.json (OpenAPI 3.1).

Base URL

Base URL
https://krinomatrix.com/global/products/world/api

Every path below goes after this, so POST /auth/login is https://krinomatrix.com/global/products/world/api/auth/login. The other region is a separate deployment with its own accounts and data. A server you run yourself is at http://<host>:8630/api.

Authentication

Sign in to the app and create a key under Settings → API keys (it starts with km_ and is shown only once), then send Authorization: Bearer <key> on every request. A key works until you delete it; if one leaks, delete it in Settings and it stops working at once.

A key can do everything the app does except manage keys and delete the account (those get 403 and need a signed-in browser). You can also log in with a password for a login token instead; it expires after a week.

Shell
API=https://krinomatrix.com/global/products/world/api
export KRINO_API_KEY=km_...   # create one under Settings → API keys

curl -s $API/characters -H "Authorization: Bearer $KRINO_API_KEY"

Streaming

POST /sessions/{sid}/stream answers with server-sent events, in this order:

EventData
decisionFirst: what the character decided to do this turn (reply, stay quiet, make a gesture…)
deltaA piece of the reply in text; join them in order
doneThe end, with the same object /messages returns
errorReplaces done if generation fails partway: {"message": "…"}
text/event-stream
event: decision
data: {"actions": ["RESPOND"], "policy": "rules"}

event: delta
data: {"text": "Once upon a time, "}

event: delta
data: {"text": "there was a big blue whale…"}

event: done
data: {"reply": {…}, "user": {…}, "actions": […], "decision": {…}, "memory_job": "…"}

If you put a reverse proxy in front, turn off response buffering for this endpoint.

Errors

Errors come back as {"detail": "…"}, written for people, in the site's language.

StatusMeaning
400The request is incomplete, for example an empty message
401Missing or deleted API key, or an expired login token
403An API key can't do this (managing keys and deleting the account need a signed-in browser)
404It doesn't exist, or it isn't yours
409The session belongs to a different character than the one you named
413 / 415The upload is too large / in a format we don't take
422The body doesn't match the schema; detail says which field
429Today's credits are used up; they reset tomorrow
502 / 503An upstream model or voice service failed; retrying usually works

Parameters

NameInTypeRequiredDescription

streambodybooloptionalStream 16-bit PCM (24 kHz mono) as it's synthesized; the first audio arrives in a fraction of a seconddefault false
